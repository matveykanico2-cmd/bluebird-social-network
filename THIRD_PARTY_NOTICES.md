# Third-party functionality references

## OpenVK

OpenVK (https://github.com/OpenVK/openvk) was reviewed for product patterns such as wall posts, channels, messages, notifications, groups, albums, polls, gifts and moderation. The repository is distributed under GNU LGPL 2.1. Bluebird uses independently implemented TypeScript/NestJS/React code and does not copy OpenVK PHP source files.

## Shalter

Shalter (https://github.com/matveykanico2-cmd/Shalter) was reviewed as the owner's messenger reference. Its documented patterns (NestJS + React, SQLite, WebSocket reconnect/catch-up, chats, groups, channels, stories, media and WebRTC) informed compatibility work. Bluebird keeps its own implementation and data schema.
